# 真人代理人版 — 分鏡與素材生成說明

## 這條線怎麼運作

人物**不是畫出來的**，是把你們 AI 代理人工具產生的影片**去背後合成**上去。
所以我這邊負責「動畫圖層 + 合成」，你們負責「產出人物片段」。

```
scene-v3.html + timeline-v3.js
        │ node render-v3.mjs
   frames/*.png（動畫圖層，人物位置留白）
        │
presenter/*.mp4（你們生成的人物影片，純色背景）
        │ ./compose.sh presenter/xxx.mp4 ep01-v3
   out/zhibao-ep01-v3.mp4
```

## 人物影片的規格（給 AI 代理人工具）

| 項目 | 要求 |
|---|---|
| 解析度 | 1080×1920（直式） |
| 背景 | **純色**。淺灰 `#D9D9D9` 或綠幕 `#00B140`，不要有陰影、不要有漸層 |
| 構圖 | 人物置中站立，頭頂留白約 8%，畫面下緣到大腿或膝蓋 |
| 服裝 | 智生活制服（深灰短袖襯衫＋薄荷綠拼接＋黑長褲） |
| 長度 | 每個動作 8–12 秒即可，`compose.sh` 會自動做來回循環 |
| 幀率 | 30fps |
| 浮水印 | **要關掉**。參考片右下角有生成工具的星形浮水印，正式素材不能留 |

去背色在 `compose.sh` 用環境變數調：

```bash
KEY=0x00B140 SIM=0.30 ./compose.sh presenter/step1.mp4 ep01-v3   # 綠幕
KEY=0xD9D9D9 SIM=0.26 ./compose.sh presenter/step1.mp4 ep01-v3   # 淺灰（預設）
```

去背有殘影就把 `SIM` 調高（0.26 → 0.32），人物邊緣被吃掉就調低。

## 需要生成的五段（對應 48 秒的分鏡）

| 段落 | 秒數 | 人物動作 | 生成提示詞（中文描述，依你們工具調整） |
|---|---|---|---|
| **A 開場** | 0–6 | 微笑看鏡頭，雙手自然交握，輕微點頭 | 年輕女性客服人員站立面對鏡頭，親切微笑，雙手在身前自然交握，輕微點頭致意，自然呼吸，純灰背景 |
| **B 第一步** | 6–19 | 右手抬起，往畫面左側（圖示方向）指 | ⋯⋯右手抬起自然指向左前方，眼神跟著手看過去，然後看回鏡頭微笑 |
| **C 第二步** | 19–33 | 做「拔」的手勢，然後比出數數的手勢 | ⋯⋯右手做出向外拉的動作，接著舉手比數字，表情耐心 |
| **D 第三步** | 33–42 | 攤手示意「等一下」，然後點頭 | ⋯⋯雙手手心向上輕輕攤開示意稍等，接著微笑點頭 |
| **E 收尾** | 42–48 | 右手比向畫面左側的電話卡片，微笑 | ⋯⋯右手掌心向上指向左方，親切微笑，像在說「打給我們」 |

生成後放進 `presenter/`，檔名 `a.mp4` `b.mp4` … 之後我可以改 `compose.sh` 讓它**依時間切換不同片段**。

## 目前的示範版用什麼

只用了你給的那支 10 秒待機片，做成來回循環撐滿 48 秒。
所以**人物動作跟旁白內容沒有對應**——這是預期中的，等五段素材生出來就會對上。

## 兩個品質提醒

1. **每段人物影片的服裝、髮型、光線要一致**，不然剪在一起會跳。
   同一次生成、同一組參數產出全部五段，不要分次生成。
2. **人物不要說話**（不要對嘴）。旁白是另外配的，對不上嘴型會非常出戲。
   要對嘴的話，人物影片就必須用最終旁白音檔去生成。
