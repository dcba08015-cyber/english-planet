# 素材與來源清單

專案裡用到的每一項外部資源，以及它的授權狀態。

## 一、圖像素材：全部是原創向量圖，沒有用任何外部照片

| 素材 | 來源 | 授權 |
|---|---|---|
| 智寶角色 | **我依智生活官方形象用 SVG 重畫**（白色圓身、小耳朵、黑豆眼、粉頰、薄荷綠菱形鼻、黑領結） | 造型著作權屬智生活科技，對外發佈前需確認商標使用範圍 |
| 手機示意圖 | 原創 SVG，寫在 `scene-v2.html` / `scene-v3.html` | 無第三方權利 |
| 數據機（含燈號、插頭、電線） | 原創 SVG | 無第三方權利 |
| 倒數時鐘 | 原創 SVG | 無第三方權利 |
| 終端機視窗（工程師版） | 原創 HTML/CSS | 無第三方權利 |
| 背景漸層與光暈 | CSS 漸層 | 無第三方權利 |

**沒有下載、也沒有使用任何圖庫照片、外部插圖或圖示集。**
畫面上看到的每一個圖形都是程式碼畫出來的，所以沒有任何授權風險，也可以任意修改顏色與造型。

## 二、字型

| 字型 | 用在哪 | 網址 | 授權 |
|---|---|---|---|
| Noto Sans TC | 全部影片的中文 | `https://fonts.googleapis.com/css2?family=Noto+Sans+TC` | SIL Open Font License 1.1，可商用 |
| Noto Serif TC | 交接文件與簡報頁標題 | `https://fonts.googleapis.com/css2?family=Noto+Serif+TC` | SIL OFL 1.1，可商用 |
| JetBrains Mono | 終端機畫面、數字標籤 | `https://fonts.googleapis.com/css2?family=JetBrains+Mono` | SIL OFL 1.1，可商用 |

渲染時由 Chromium 直接向 Google Fonts 取用，**離線環境會 fallback 成系統字型**，
所以本機渲染時要確認能連上 `fonts.googleapis.com`，否則中文會變方框或換一種字型。
